Featured work

Things I've built

A few systems from my work, described without client details, plus one personal project.

Snowflake + Python

Data quality framework

Checks each batch before it loads, sets aside bad rows with the reason and the pipeline run that caused them, and lets clean rows through. New sources need no manual setup. Pipeline failures dropped by about 30%.

SFTP · APIs · S3

File exchange for a corporate merger

Pulls files from SFTP, S3, APIs, and SharePoint and delivers them externally with encryption, record-count checks, and an audit log of every transfer, plus alerts when a delivery misses its deadline.

Automation + AI

Self-healing production jobs

Failed jobs restart on their own, and critical failures email the on-call team an AI-written explanation of what went wrong and a suggested fix.

AWS Glue

Splitting a 12,000-line Glue job

Broke one oversized job into four smaller ones, with an optional middle step that only runs when it's needed, which lowered our Glue costs.

dbt + Snowflake

Tested dbt models

Built dbt models with automated tests and Git-based CI/CD, so data problems were caught before they reached dashboards used by 20+ stakeholders.

dbt + BigQuery

IMDb data warehouse

A personal project. Pulled movie data from APIs, cleaned it with Gemini, and loaded it into a normalized BigQuery warehouse with layered dbt models and snapshots for history.
